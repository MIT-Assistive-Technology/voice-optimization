# About the Project
Project working with a Senior from Harvard regarding better voice detection

Student has been using Talon for a while. Talon does a decent job controlling the computer. However, it has trouble working in environments with any background noise. Also, the student has been using ChatGPT for equations and this requires button pressing. 

This project will look to solve the issues previously mentioned and allow the student to use their computer in any environment with the least amount of hand usage. 
For voice isolation, we plan to use MetalVoice to filter out background noise and BlackHole to route the processed audio output into Talon as its input.
